# Query Streams — AI-client playbook

Teaches your AI client how to work with your databases through Query Streams: read the real schema before writing SQL,
write SQL that runs first time on your engine, and use held results and analysis tools when they pay off.

**Install (Claude Code, Codex, Cursor, Gemini CLI and other skills-aware agents):**

    npx skills add querystreams/skills

**Or** copy `AGENTS.md` into your project root — most coding agents read it with no configuration. `CLAUDE.md` and
`GEMINI.md` are the same text under the file names those tools read.

**Tailored copy:** the Query Streams Portal renders this playbook for your own connectors and plan — open
**Streams → Live → MCP → Connections → Teach your AI client**. The version there may list only the database engines
you actually use.
